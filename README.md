# Desafios de Desenvolvimento Técnico

Este repositório contém soluções para os desafios propostos, desenvolvidos em JavaScript.

## Estrutura

- **Desafio 1:** Soma de variável com estrutura de repetição.
- **Desafio 2:** Verificação de número pertencente à sequência de Fibonacci.
- **Desafio 3:** Análise de faturamento de uma distribuidora.
- **Desafio 4:** Cálculo do percentual de faturamento por estado.
- **Desafio 5:** Função para inverter os caracteres de uma string.

## Instruções

1. Clone este repositório:

   ```bash
   git clone https://github.com/seu_usuario/Desafios_Desenvolvimento.git
   ```

2. Navegue até o diretório de cada desafio e execute os arquivos `.js` usando Node.js:
   ```bash
   node nome_do_arquivo.js
   ```
